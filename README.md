# 🌴 Turismo Praia Grande

Este projeto é uma página web simples desenvolvida em **HTML** utilizando o framework **W3.CSS** para estilização.  
O objetivo é apresentar pontos turísticos da cidade de **Praia Grande**, com imagens e títulos organizados em cartões responsivos.

---

## 🧭 Funcionalidades

- Exibição de diferentes pontos turísticos com imagens ilustrativas.  
- Layout responsivo utilizando classes do W3.CSS (`w3-card`, `w3-third`, `w3-row-padding`, etc.).  
- Estrutura limpa e fácil de expandir com novos locais.
